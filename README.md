# kcf — Next.js + React 개발 환경

간단한 Next.js (React) 프로젝트 템플릿입니다.

빠른 시작:

```cmd
cd /d C:\Users\user\Documents\GitHub\kcf
npm install
npm run dev
```

- 개발 서버: http://localhost:3000
- 주요 파일: `pages/index.js`, `pages/_app.js`, `styles/globals.css`

추가 요청(옵션): TypeScript, Tailwind, ESLint/Prettier 설정 등을 원하면 알려주세요.
